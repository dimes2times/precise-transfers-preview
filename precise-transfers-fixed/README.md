# Precise Transfers — corrected website

Read INSTALL-FIX.md first. Double-click START-WEBSITE.cmd or index.html.
In VS Code, open this whole folder and choose “Precise Transfers — open website”.
No installation, server or build step is required.

Pages: index.html, about.html, booking.html, faq.html, policies.html.
Styling: css/styles.css plus css/mockup.css. Both are required.
Behavior: js/main.js. Assets: assets/images and assets/fonts.

Requests prepare an email for the visitor to send. Online payments are not connected.
The 2021 image is illustrative. The site remains marked noindex during development.
